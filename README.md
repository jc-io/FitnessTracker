# FitnessTracker
Exercise Library: A pre-populated list of movements (Squat, Bench Press, Deadlift, Pull-ups) categorized by primary muscle group and equipment (barbell, dumbbell, cable, machine, bodyweight).

Workout Logger:

Add exercises on the fly or load a routine.

Log sets: Weight, Reps, and a checkbox to mark complete.

Support set types: Normal, Warm-up, Drop set, Failure.

Rest Timer: Automatically triggers when a set is checked off (with customizable intervals, e.g., 90s, 3m).

History / Logbook: View past workouts, dates, and what was lifted.

Basic PR Tracking: Automatically flag when a user hits a new Personal Record (e.g., max weight, max volume).
